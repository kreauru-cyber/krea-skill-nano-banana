# Krea · Skill de prompts para Nano Banana

Skill gratuita de [Krea](https://instagram.com/krea_uy) para Claude. Le pasás una idea o una foto de referencia y Claude te devuelve un prompt ultrarrealista para Nano Banana, listo para pegar.

📘 **[Ver la guía visual en PDF](./Krea-Skill-Nano-Banana.pdf)**

## Qué hace

- Escribe los prompts en inglés y en formato 4:5.
- Busca un look de foto de celular real, sin aspecto de render.
- Saca personas atractivas y naturales.
- Si la referencia tiene una modelo real, la cambia por una cara nueva.
- Toma la referencia como base, sin copiarla.
- Mantiene tu cara 1:1 si usás tus propios character sheets (@image1, @image2).

## Cómo instalarla

**Necesitás** Claude Pro, Max, Team o Enterprise, con la ejecución de código activada en Configuración → Capacidades.

### Opción 1: subir el ZIP
1. Descargá [`krea-prompt-nano-banana.zip`](./krea-prompt-nano-banana.zip). Tocá el archivo y después el botón de descarga.
2. En Claude, andá a **Configuración → Capacidades → Skills → Upload skill**.
3. Elegí el ZIP, sin descomprimirlo, y activá la skill.

### Opción 2: pegarla en Claude
1. Abrí [`krea-prompt-nano-banana/SKILL.md`](./krea-prompt-nano-banana/SKILL.md) y copiá todo el texto.
2. En un chat nuevo de Claude escribí *"Guardá esto como una skill en mi cuenta"* y pegá el texto.
3. Confirmá en la tarjeta que aparece.

## Cómo usarla

No hace falta nombrarla, Claude la usa solo cuando le pedís un prompt de imagen:

- *"Haceme un prompt para Nano Banana de una chica tomando un café en una terraza al atardecer."*
- *"Mirá esta foto y haceme un prompt con la misma idea, pero con otra modelo."*
- *"Poneme a mí (@image1) caminando por la rambla con una campera de jean."*
